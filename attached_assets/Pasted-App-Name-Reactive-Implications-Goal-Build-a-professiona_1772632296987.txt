App Name: Reactive Implications
Goal:
Build a professional global risk intelligence dashboard web application similar to worldmonitor.app. The application should be map-first, showing global events with layers, filters, and AI-assisted strategic analysis.
The platform is used for strategic risk oversight, geopolitical monitoring, and decision support.
Technology Stack (must follow)
Frontend
React
Vite
TypeScript
TailwindCSS
Map
MapLibre GL JS (open-source Mapbox alternative)
Backend
Node.js
Express
Data
Seed data stored locally as JSON
Designed so APIs can later connect to external data feeds
