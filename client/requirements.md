## Packages
maplibre-gl | Interactive world map rendering engine
react-map-gl | React wrapper for MapLibre GL
framer-motion | Complex animations and page transitions
recharts | Data visualization for sector heatmap and trends
date-fns | Formatting dates for events and intelligence reports

## Notes
- MapLibre uses CartoDB Dark Matter style which does not require an API key
- Global Situation map expects a 100vh layout container
- UI design targets a high-density, "command center" / "Palantir" aesthetic with dark themes and tech-focused typography
